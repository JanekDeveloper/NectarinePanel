# Архитектура

[English](../en/architecture.md) · [Українська](../uk/architecture.md) · **Русский** · [Polski](../pl/architecture.md)

NectarinePanel состоит из Nuxt-клиента, FastAPI API, PostgreSQL, Valkey и Celery worker. Nginx принимает TLS-трафик и направляет запросы к клиенту и API.

## Границы ответственности

- API хранит проекты, пользователей, роли, аудит, конфигурацию и зашифрованные секреты.
- Worker выполняет задачи развёртывания, резервного копирования и обслуживания.
- System Agent — единственный компонент с повышенными правами: он управляет systemd, Docker, файлами внешних корней и сетевыми действиями.
- Релизы проекта хранятся отдельно; `current` указывает на активный релиз.

## Доступ и ресурсы

Глобальные роли и участники проекта ограничивают доступ к данным и операциям. Политики ресурсов задают CPU/RAM для Docker и systemd; место на диске пока только контролируется. Для Docker Compose политика остаётся режимом мониторинга.

## Наблюдаемость

Worker сохраняет метрики хоста и проектов. При превышении лимита ресурсов создаётся дедуплицированное уведомление; Telegram доставляет оповещения, если он настроен.
