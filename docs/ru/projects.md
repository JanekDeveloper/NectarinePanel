# Проекты

[English](../en/projects.md) · [Українська](../uk/projects.md) · **Русский** · [Polski](../pl/projects.md)

Проект связывает исходный код или файлы, среду выполнения, переменные, домены, задачи, базы и историю развёртываний.

## Развёртывание

Используйте Git или ZIP-архив. Для приватного Git-репозитория настройте отдельные учётные данные или deploy key в настройках проекта. История релизов позволяет просмотреть журнал и откатиться на успешный выпуск.

## Безопасность и эксплуатация

- Секреты храните во вкладке **Переменные**, не в репозитории.
- Назначайте пользователей проекту с минимальной нужной ролью.
- Задавайте CPU/RAM/Disk в **Настройках → Ограничения ресурсов**; Compose пока только мониторится.
- Внешние импортированные каталоги читаются, скачиваются и архивируются через System Agent, без выдачи API лишних прав.
- Перед удалением проекта сохраните нужные данные и резервные копии.
