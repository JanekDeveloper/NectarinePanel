# Мониторинг

[English](../en/monitoring.md) · [Українська](../uk/monitoring.md) · **Русский** · [Polski](../pl/monitoring.md)

Панель собирает CPU, память, диск, сеть и состояние health check. Метрики одного проекта доступны через `GET /api/v1/monitoring/projects/{project_id}/latest`; список последних метрик — через `GET /api/v1/monitoring/projects/latest`.

Если включена политика ресурсов, образец метрик содержит лимиты и нарушения. Превышение лимита создаёт дедуплицированное уведомление. Отсутствие метрик означает «Нет данных», а не ошибку проекта.

Настройте Telegram, чтобы получать уведомления вне веб-интерфейса.
