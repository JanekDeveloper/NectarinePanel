# Telegram

[English](../en/telegram.md) · [Українська](../uk/telegram.md) · **Русский** · [Polski](../pl/telegram.md)

Telegram-бот подтверждает вход и доставляет уведомления о событиях панели. Создайте бота через BotFather, сохраните токен только в защищённой конфигурации панели и привяжите разрешённый чат в настройках.

Проверьте подтверждение входа и тестовое уведомление. Если бот не отвечает, проверьте запущенную службу, токен, доступ к Telegram API и журнал без публикации токена.
