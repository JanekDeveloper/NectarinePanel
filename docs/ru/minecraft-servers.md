# Paper, Purpur и Spigot

[English](../en/minecraft-servers.md) · [Українська](../uk/minecraft-servers.md) · **Русский** · [Polski](../pl/minecraft-servers.md)

Панель позволяет установить Minecraft-сервер, настроить его, добавить плагины
и управлять игроками. Для серверов с модами Forge используйте
[отдельное руководство](minecraft-forge.md).

## Создание и запуск

1. Откройте **Проекты → Новый проект** и выберите шаблон Paper, Purpur или
   Spigot. Для другого ядра потребуется отдельный проект.
2. Перейдите на страницу **Minecraft** созданного проекта. Укажите память и
   свободные порты. Включите RCON для консоли и управления игроками; можно
   задать свой пароль или оставить его автоматическую генерацию.
3. Прочитайте и примите EULA Minecraft, затем сохраните настройки.
4. Выберите версию Minecraft и сборку. Панель подберёт Java автоматически.
   Запустите установку и дождитесь завершения; установка Spigot может занять
   больше времени.
5. Нажмите **Запустить**. Подключайтесь из Minecraft по адресу VPS и игровому
   порту, например `play.example.com:25565`.

Если у вас уже есть серверный JAR выбранного ядра, используйте **Импорт
серверного JAR**: выберите версию Minecraft и загрузите файл.

## Настройки и консоль

На странице **Minecraft** можно изменить память, порты и настройки сервера.
`Xms` — начальный объём памяти, `Xmx` — максимальный. Оставьте часть памяти VPS
для панели и других проектов.

Перед изменениями остановите сервер. Игровые настройки редактируйте в разделе
конфигураций, затем сохраните их и запустите сервер. Для команд и диагностики
используйте вкладки **Консоль** и **Логи**.

## Плагины и игроки

В разделе **Плагины** загрузите JAR совместимого плагина. Для замены загрузите
новый JAR с тем же именем файла. Плагины можно включать, отключать и удалять
только при остановленном сервере. Их данные сохраняются при удалении JAR.
После изменений запустите сервер.

В разделе **Игроки** укажите имя игрока и выберите действие: добавить или
удалить из whitelist, выдать или снять OP, забанить, разбанить или кикнуть.
Сервер должен быть запущен, а RCON — включён.

## Обновления и резервные копии

Выберите нужную версию и сборку, затем нажмите **Обновить с бэкапом**. Панель
создаст полную резервную копию перед заменой сервера. Дождитесь завершения
операции; при ошибке проверьте её результат и логи. Если доступна кнопка
**Повторить восстановление**, используйте её для повторной попытки отката.

Копии создаются и восстанавливаются во вкладке **Резервные копии**. Для копирования
работающего сервера нужен RCON; иначе сначала остановите сервер. Восстановление
заменяет текущие данные копией. Для возврата на старую версию Minecraft
восстановите копию этой версии. Храните важные копии также вне VPS.

## Состояние сервера

Страница **Minecraft** показывает доступность сервера, число игроков, описание
и версию. Нагрузка на ресурсы доступна в обзоре проекта. Если подключён
Telegram-бот, через него можно запускать, останавливать и перезапускать сервер,
создавать копии и получать уведомления.

Другие возможности панели описаны в [руководстве пользователя](user-guide.md).
