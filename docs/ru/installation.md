# Установка

[English](../en/installation.md) · [Українська](../uk/installation.md) · **Русский** · [Polski](../pl/installation.md)

Поддерживаемая целевая система — Ubuntu 24.04 LTS. Перед установкой подготовьте домен, TLS, DNS, исходящую сеть, Docker (если нужен) и отдельное хранилище резервных копий.

Установщик создаёт системных пользователей и службы, конфигурацию Nginx, PostgreSQL/Valkey, worker и System Agent. После установки войдите под владельцем и сразу смените временные учётные данные.

Для обновления используйте только проверенный релиз и штатный `installer/update.sh`; подробный безопасный порядок описан в [руководстве пользователя](user-guide.md#обновление-панели).
