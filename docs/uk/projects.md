# Проєкти

[English](../en/projects.md) · **Українська** · [Русский](../ru/projects.md) · [Polski](../pl/projects.md)

Проєкт поєднує джерело коду або файли, середовище виконання, змінні, домени, завдання, бази та історію розгортань.

Використовуйте Git або ZIP. Для приватного репозиторію налаштуйте окремі облікові дані або deploy key. Секрети зберігайте у вкладці **Змінні**, не в Git. Призначайте учасникам мінімальну потрібну роль. У **Налаштуваннях → Обмеження ресурсів** задавайте CPU/RAM/Disk; Compose поки лише моніториться.

Перед видаленням збережіть дані й резервні копії. Захищені зовнішні каталоги завантажуються та архівуються через System Agent.
