# Telegram

[English](../en/telegram.md) · **Українська** · [Русский](../ru/telegram.md) · [Polski](../pl/telegram.md)

Telegram-бот підтверджує вхід і надсилає сповіщення панелі. Створіть бота через BotFather, збережіть токен лише в захищеній конфігурації та прив’яжіть дозволений чат у налаштуваннях.

Перевірте підтвердження входу й тестове сповіщення. Якщо бот не відповідає, перевірте службу, токен, доступ до Telegram API та журнал, не публікуючи токен.
