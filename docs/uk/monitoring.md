# Моніторинг

[English](../en/monitoring.md) · **Українська** · [Русский](../ru/monitoring.md) · [Polski](../pl/monitoring.md)

Панель збирає CPU, пам’ять, диск, мережу та стан health check. Метрики проєкту доступні через `GET /api/v1/monitoring/projects/{project_id}/latest`, а останні метрики всіх доступних проєктів — через `GET /api/v1/monitoring/projects/latest`.

За ввімкненої політики ресурсів зразок містить ліміти й порушення. Перевищення створює дедупліковане сповіщення. Відсутність метрик означає «Немає даних», а не помилку проєкту.
