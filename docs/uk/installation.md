# Встановлення

[English](../en/installation.md) · **Українська** · [Русский](../ru/installation.md) · [Polski](../pl/installation.md)

Підтримувана система — Ubuntu 24.04 LTS. Перед встановленням підготуйте домен, TLS, DNS, вихідну мережу, Docker за потреби та окреме сховище резервних копій.

Інсталятор створює системних користувачів і служби, Nginx, PostgreSQL/Valkey, worker та System Agent. Після встановлення увійдіть власником і змініть тимчасові облікові дані.

Для оновлення використовуйте лише перевірений реліз і штатний `installer/update.sh`; порядок наведено в [посібнику користувача](user-guide.md#оновлення-панелі).
