# Архітектура

[English](../en/architecture.md) · **Українська** · [Русский](../ru/architecture.md) · [Polski](../pl/architecture.md)

NectarinePanel складається з Nuxt-клієнта, FastAPI API, PostgreSQL, Valkey і Celery worker. Nginx приймає TLS-трафік та спрямовує запити до клієнта й API.

- API зберігає проєкти, користувачів, ролі, аудит, конфігурацію і зашифровані секрети.
- Worker виконує розгортання, резервне копіювання та фонове обслуговування.
- System Agent — єдиний компонент із підвищеними правами: він керує systemd, Docker і зовнішніми коренями файлів.
- Релізи зберігаються окремо, а `current` вказує на активний реліз.

Глобальні ролі та учасники проєкту обмежують доступ. Політики ресурсів застосовують CPU/RAM для Docker і systemd; диск наразі лише контролюється. Worker збирає метрики й створює дедупліковані сповіщення про перевищення лімітів.
