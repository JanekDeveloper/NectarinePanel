# Instalacja

[English](../en/installation.md) · [Українська](../uk/installation.md) · [Русский](../ru/installation.md) · **Polski**

Obsługiwanym systemem docelowym jest Ubuntu 24.04 LTS. Przed instalacją przygotuj domenę, TLS, DNS, sieć wychodzącą, Docker jeśli jest potrzebny i osobne miejsce na kopie zapasowe.

Instalator tworzy użytkowników systemowych i usługi, Nginx, PostgreSQL/Valkey, worker oraz System Agent. Po instalacji zaloguj się jako właściciel i zmień tymczasowe dane dostępowe.

Do aktualizacji używaj tylko zaufanego wydania i standardowego `installer/update.sh`; bezpieczną kolejność opisuje [podręcznik użytkownika](user-guide.md#aktualizacja-panelu).
