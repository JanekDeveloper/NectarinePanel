# Telegram

[English](../en/telegram.md) · [Українська](../uk/telegram.md) · [Русский](../ru/telegram.md) · **Polski**

Bot Telegram potwierdza logowanie i dostarcza powiadomienia panelu. Utwórz bota przez BotFather, przechowuj token wyłącznie w chronionej konfiguracji i przypisz dozwolony czat w ustawieniach.

Sprawdź potwierdzenie logowania i powiadomienie testowe. Jeśli bot nie odpowiada, sprawdź usługę, token, dostęp do Telegram API i log bez ujawniania tokena.
