# Projekty

[English](../en/projects.md) · [Українська](../uk/projects.md) · [Русский](../ru/projects.md) · **Polski**

Projekt łączy kod źródłowy lub pliki, środowisko uruchomieniowe, zmienne, domeny, zadania, bazy i historię wdrożeń.

Użyj Git albo ZIP. Dla prywatnego repozytorium skonfiguruj osobne dane dostępowe lub deploy key. Sekrety przechowuj na karcie **Zmienne**, nie w Git. Nadawaj członkom tylko potrzebną rolę. W **Ustawienia → Limity zasobów** określ CPU/RAM/Disk; Compose jest obecnie tylko monitorowany.

Przed usunięciem zachowaj dane i kopie zapasowe. Chronione zewnętrzne katalogi są pobierane i archiwizowane przez System Agent.
