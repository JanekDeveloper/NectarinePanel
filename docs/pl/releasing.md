# Wydawanie wersji

[English](../en/releasing.md) · [Українська](../uk/releasing.md) · [Русский](../ru/releasing.md) · **Polski**

Przed wydaniem zaktualizuj CHANGELOG, uruchom pełny zestaw testów, analizę statyczną i sprawdzenie migracji. Twórz niezmienny tag tylko z przetestowanego commitu.

Sprawdzaj aktualizację na osobnym VPS lub kopii zapasowej. Nie wydawaj wersji z niezapisanymi migracjami, tymczasowymi kluczami ani danymi deweloperskimi.
