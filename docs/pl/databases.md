# Bazy danych

[English](../en/databases.md) · [Українська](../uk/databases.md) · [Русский](../ru/databases.md) · **Polski**

Panel zarządza połączeniami obsługiwanych baz danych i przypisuje je do projektów. Dane dostępowe widzą tylko użytkownicy z właściwym uprawnieniem.

Utwórz bazę w projekcie albo w sekcji **Bazy danych**, a ciąg połączenia przechowuj jako sekret projektu, nie w Git. Przed usunięciem utwórz i sprawdź kopię zapasową. Usuwanie jest zadaniem asynchronicznym.
